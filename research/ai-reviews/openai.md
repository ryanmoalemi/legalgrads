High-level: Solid start, but tighten PRA mechanics, verification, and LRS/advertising safeguards. Add accuracy controls and clarify CPRA, scraping, and email laws.

Factual corrections
- PRA fees: For electronic records (e.g., CSV), per‑page copy fees don’t apply. Agencies may charge only the direct cost of producing the copy and, if needed, data extraction/programming costs. Cite your request under Gov. Code §6253.9. Remove “10¢/page” for CSV.
- CPRA: The “publicly available” carve‑out is not purpose‑limited. Publicly available info from government records is excluded from “personal information.” See Civ. Code §1798.140(v)(2). Keep opt‑outs as a business choice, but fix the rationale.
- Pass list timing: Don’t hardcode “Mon Nov 2, 2026, 8:00 a.m. PT.” CA Bar varies timing and typically posts applicant results first and public list later. Verify on the exam page before scheduling.
- Verification flow: You can’t email the “official” State Bar email if it’s non‑public. Adjust verification methods (see below).
- Bar numbers: They’re roughly chronological but not a reliable proxy for admit date; expect gaps/out‑of‑order assignments. Treat “blocks” as heuristic only.

Legal and data risks to add or sharpen
- Scraping/CFAA/TOU: Public‑page scraping that doesn’t bypass technical barriers is unlikely a CFAA violation in the Ninth Circuit (hiQ Labs v. LinkedIn, 31 F.4th 1180 (9th Cir. 2022)). Still, breaching site Terms of Use can trigger contract/trespass claims. Locate and comply with the State Bar TOU; prefer PRA over scraping.
- LRS exposure: Your §6155/Jackson v. LegalMatch analysis is right. Also avoid intercepting or “routing” contact forms; link out (mailto/tel) so users contact lawyers directly. No pay‑per‑lead; avoid any “recommendation.”
- Email marketing: Besides CAN‑SPAM, comply with California’s anti‑spam law (no deceptive headers/subjects). See B&P §17529.5.
- Specialization: If you display “practice areas,” add a clear “self‑reported; not a State Bar certified specialist” disclaimer to avoid implied specialization.
- Defamation/false light: Inaccurate or stale statuses can create risk. Show “last verified” timestamps and update frequently.
- Security/breach: If you store emails or other PII, implement reasonable security and a breach response consistent with Civ. Code §1798.82.

Concrete improvements
- PRA request: Ask for a machine‑readable CSV (Gov. Code §6253.9) with: bar number, full name, admit date, current status/effective date, official city/state, law school, public email/phone/website where available. Request quarterly refreshes or a standing update.
- Update cadence: Automate weekly status checks; display last‑checked date; auto‑suppress suspended/inactive within 24 hours.
- Minimal unclaimed profiles: Name, city, law school, admit year, link to Bar profile; label “Unclaimed—sourced from State Bar public record.” No photos/ratings. Consider noindex until claimed.
- Verification: Use (a) postcard with code to official address; (b) DNS/file verification on a website listed on the Bar profile; (c) bar‑card selfie plus dynamic selfie (stored briefly, then purged). Avoid weak LinkedIn/email “matches.”
- Opt‑outs/CPRA hygiene: Provide an easy removal request; if you later use cross‑context ads, add “Do Not Sell or Share” controls.
- Disclosures: Add non‑endorsement and no‑affiliation notices; attribution/link to the State Bar; practice‑area disclaimer.
- Scraping hygiene (if used): Identify a contact in User‑Agent, throttle/backoff, cache, and honor robots/TOU.
- Outreach: Include physical address and one‑click unsubscribe; avoid deceptive subjects (B&P §17529.5); no LinkedIn automation.
