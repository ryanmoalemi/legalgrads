# Legalgrads design assets for Grok

- `logos/`: original SVG recreations of the approved cap-and-column mark, horizontal lockup, and wordmark. These are vector approximations, not exact source exports.
- `headshots/`: 12 cropped AI-generated fictional demo portraits from `brand_reference.png`; inspect for artifacts and replace with individually generated or licensed photos before production. Names, credentials and schools on reference board are fictional placeholders.
- `icons/specialties/`: eight consistent minimalist SVG icons.
- `icons/benefits/`: four consistent minimalist SVG icons.
- `brand_reference.png`: visual reference board, not a replacement for individual assets.

## Typography
Use **Plus Jakarta Sans** (800 headings, 600 UI) and **Inter** (400/500 body). For handwritten annotations use **Caveat** (600/700). These are suggested close matches; the original mockup did not specify a verified exact font. Obtain fonts directly from Google Fonts under their licenses; no font files are bundled.

## Colors
Navy #0B0B3B, purple #7A00FF, pink #FF008A, orange #FF6B22, cream #FFF8F1, mint #00C5A2.

## Demo integrity
All attorney identities, rates, schools, and credentials are fictional. Mark verification as simulated. Never show fictional reviews or press endorsements as real.
